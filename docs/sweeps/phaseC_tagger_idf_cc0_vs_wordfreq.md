## Summary: CC0 table swap (license) vs wordfreq

- **Bundled default now:** `cv-en-cc0`, word frequencies computed from Mozilla Common Voice English sentences
  (CC0 1.0; see `NOTICE.md`, `packages/core/src/wordfreq/FREQ_LICENSE.md`). **wordfreq small_en (CC BY-SA 4.0)**
  is dev-only: `research/wordfreq/`, selected here via `{"kind":"keyphrase-idf","freqFile":...}`.
- **Same run, same scorer:** top-3 **21/144** (CC0) vs **23/144** (wordfreq) vs 3/144 (keyphrase-only baseline);
  top-1 11 vs 11; ledger holds 37 vs 41. Each `hud.tagger.freq` in the jsonl confirms which table ran.
- **Why wordfreq is 23 here and 13/144 in `phaseC_tagger_track1.md`:** the tagger output did not change. The
  wordfreq column's 144 final labels are identical to the track1 jsonl, and a rebuild of the pre-swap code
  (f85faeb) gives the same 23/144. The difference is the scorer input: the sim's `personas.json` / `personas_c.json`
  (read by rescore.py) were modified at 2026-11-02 00:13 PT, after track1 ran (that edit was not made from this repo).
  Under the current scorer, track1 numbers would read 23/144 (idf) and 3/144 (baseline).
- CC0 corpus caveat: Wikipedia/read-speech register. Historical/encyclopedic words read as more common
  (byzantine 4.3 vs 3.3, medieval 4.8 vs 4.0) and chat words as rarer (yeah 3.7 vs 5.4, kids 4.4 vs 5.3), which
  costs ~2 sessions (chatty group 1/36 vs 0/36, medium 14/54 vs 16/54, terse 6/54 vs 7/54).
- Leak checks with the CC0 table: both PASS (`phaseC_tagger_idf_cc0_leak_check.txt`).
